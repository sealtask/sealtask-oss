# Contributing

`sealtask/sealtask-oss` is a read-only public mirror. Its `main` branch and
release tags are updated only by SealTask's fast-forward-only subtree
publisher.

Issues and pull requests are welcome as proposals and review artifacts, but
maintainers do not merge public pull requests directly. An accepted change is
reproduced in the upstream development repository, validated there, and then
arrives here through the normal mirror. This preserves one linear public
history and prevents the publisher from overwriting outside contributions.

Security vulnerabilities should not be filed publicly. Follow
[`SECURITY.md`](./SECURITY.md) instead.
